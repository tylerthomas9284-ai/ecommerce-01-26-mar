💻 HOW TO RUN THE WEBSITE
═══════════════════════════════════════════════════════════════════

OPTION 1: Direct Browser Opening (Simplest)
──────────────────────────────────────────────
  1. Double-click on "index.html"
  2. It will open in your default browser
  3. The website will work immediately!
  
  ✅ Pros: Super easy, no setup required
  ⚠️ Note: Some features work best with a local server


OPTION 2: Using Python (Recommended)
──────────────────────────────────────────────
  1. Open Terminal/Command Prompt
  2. Navigate to your website folder:
     
     cd path/to/cartnova-website
  
  3. Run this command (Python 3):
     
     python -m http.server 8000
  
  4. Open browser and visit:
     
     http://localhost:8000
  
  ✅ Pros: Best performance, all features work perfectly


OPTION 3: Using VS Code Live Server
──────────────────────────────────────────────
  1. Install "Live Server" extension in VS Code
  2. Right-click on "index.html"
  3. Select "Open with Live Server"
  4. Website opens automatically in browser
  
  ✅ Pros: Auto-refresh on file changes, great for editing


OPTION 4: Using Node.js http-server
──────────────────────────────────────────────
  1. Install http-server globally:
     
     npm install -g http-server
  
  2. Navigate to your website folder:
     
     cd path/to/cartnova-website
  
  3. Run:
     
     http-server
  
  4. Visit the URL shown (usually http://localhost:8080)

🛠️ CUSTOMIZATION
═══════════════════════════════════════════════════════════════════

Adding Products
──────────────────────────────────────────────
Edit data.js and add new product objects:

  {
    id: 'unique-id',
    name: 'Product Name',
    price: 99,
    image: 'https://image-url.com/image.jpg',
    category: 'Category Name',
    gender: 'men' or 'women',
    description: 'Product description',
    sizes: ['S', 'M', 'L', 'XL']
  }


Changing Colors
──────────────────────────────────────────────
Edit the :root variables in styles.css:

  --primary-color: #111827;      (Main dark color)
  --accent-color: #3b82f6;       (Blue accent)
  --background: #ffffff;          (White background)
  --background-alt: #f9fafb;     (Light gray background)


Updating Text Content
──────────────────────────────────────────────
All text can be edited directly in the HTML files.
Just open the file and change the text you want.

❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Cart not working?
  → Make sure JavaScript is enabled in your browser
  → Check browser console for errors (F12)
  → Clear localStorage and try again

Images not loading?
  → Check your internet connection (images load from Unsplash CDN)
  → Try refreshing the page
  → Check browser console for 404 errors

Styles look broken?
  → Make sure styles.css is in the same folder as HTML files
  → Clear browser cache (Ctrl+Shift+Delete)
  → Check file name is exactly "styles.css" (lowercase)

Features not working?
  → Make sure ALL JavaScript files are downloaded
  → Check they're in the same folder as HTML files
  → Open browser console (F12) to check for errors
